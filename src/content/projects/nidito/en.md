Nidito is built around trust between families: every listing shows who sells
it, sellers have a profile and ratings, and selling is free of commission.
Buyers browse a feed, save favorites, message the seller and place orders.

The app runs as a Cloudflare Worker and uses Supabase for sign-in, the
database and file storage. Database rules decide who can read or change each
row, and they are covered by database tests and by Playwright end-to-end
tests.

The source code is private. The live site is public.

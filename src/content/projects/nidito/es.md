Nidito se basa en la confianza entre familias: cada publicación muestra quién
vende, los vendedores tienen perfil y calificaciones, y vender no tiene
comisión. Los compradores recorren un feed, guardan favoritos, escriben al
vendedor y hacen pedidos.

La aplicación se ejecuta como un Cloudflare Worker y usa
Supabase para el inicio de sesión, la base de datos y el almacenamiento de
archivos. Las reglas de la base de datos determinan quién puede leer o
modificar cada fila, y están cubiertas por pruebas de base de datos y por
pruebas de extremo a extremo con Playwright.

El código fuente es privado. El sitio en producción es público.
